# Vanessa Duran | Couture 3D

Site responsivo de apresentação de coleção couture com a foto fornecida integrada em `assets/look-couture.jpg`.

## Executar
Abra `index.html` no navegador ou publique a pasta em um serviço de hospedagem estática (Vercel, Netlify ou GitHub Pages).

## Recursos
- Layout responsivo e navegação mobile
- Imagem principal e cards de coleção usando a imagem fornecida
- Filtros de categoria
- Seleção de peças em painel lateral
- Solicitação via WhatsApp (abre compartilhamento; configure um número no link `wa.me` para direcionar ao atendimento)

**Aviso:** este é um catálogo demonstrativo. Não processa pagamentos nem confirma estoque.
